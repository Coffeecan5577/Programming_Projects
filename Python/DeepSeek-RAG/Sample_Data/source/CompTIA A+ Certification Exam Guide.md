#### Chapter 1: Safety and Professionalism

##### Talking Points of the Chapter
1. Learn how to present yourself with a proper appearance and professional manner
2. Talk to customers in a professional, productive manner
3. Discuss the tools of the trade and preparations necessary to deal with problems proactively
4. Use common safety procedures
5. Apply the best practice methodology to resolve problems

**Traits of a Tech**
1. Honesty/Integrity - Honesty means telling the truth, and integrity means doing the right thing, even when no one is looking
2. Dependability/Responsibility - A dependable person performs agreed-upon actions, and a responsible person is answerable for those actions.
3. Effective Communication - subsections listed below:
	1. Assertive Communication - Assertive communication is not pushy or bossy, but it is also not the language of a pushover. To do this, first show the other person that you understand and appreciate the importance of their feelings. Avoid using the word "you", because it can come across as accusatory. Make sure you understand the problem clearly without accusing the user directly. Next and lastly, tell the user what you need to prevent this error in the future.
	2. Respectful Communication - Follow the Ethic of Reciprocity, or the Golden Rule essentially. Make sure to follow the rules of civil conversation:
		1. *Actively Listen*
		2. *Avoid interrupting the customer as they describe the problem*
		3. *Just listen and take notes*
	3. Getting Answers - Make sure you are asking the right questions and also listening to the customers' answers. You can also repeat back the problem to the customer once they have finished speaking to ensure that you fully understand the issue.
	4. Expectations and Follow-Up:
		1. Timeline - Try to establish a clear timeline of repairs to the customer and do your best to always stay in communication with them about the repairs themselves.
		2. Options - Offer repair/replacement options as needed and let the customer decide on which route they want to take.
		3. Documentation - At the completion of your work, provide proper documentation of services performed. 
4. Be Prepared! - This section will cover how to handle computing devices like a professional:
	1. Electrostatic Discharge:
		1. Antistatic tools - The key to avoiding ESD is to keep yourself and the computer you are working on grounded at the same level of potential electric energy. You can accomplish this by using an ESD strap that connects to the computer on one end, and to your bare wrist on the other end. You can also use antistatic mats that contain resistors to help ground the PC you are working on, along with antistatic bags (Make sure to store PC components inside the bag, and not on it.) **Exam Tip** - *Always disconnect power before repairing a computing device.* 

**Troubleshooting Methodology**
An effective troubleshooting methodology includes:
	1. Talking to users to determine how and when the problem took place
	2. Determining a cause
	3. testing
	4. verification
	5. Documentation
CompTIA defines their own methodology in this chapter:
	1. *Identify the problem*
		1. Gather information from the user, identify user changes and if possible, perform backups before making changes
		2. Inquire regarding environmental/infrastructure changes
	2. *Establish a theory of probable cause*
		1. Conduct internal or external research based on symptoms
	3. *Test the theory to determine the cause*
		1. Once the theory is confirmed, determine next steps to resolve the problem
	4. *Establish a plan of action* to resolve the problem and implement a solution
		1. Refer to vendor documentation or instruction for guidance
	5. *Verify full system functionality* and if applicable, implement preventative measures
	6. *Document* findings, actions and outcomes

##### The Computing Parts
Computers consist of three major components:
1. Hardware
2. Operating System
3. Applications

##### Stages
At the most basic level, computers work through three stages, in what's known as the *computing process*:
1. Input
2. Processing
3. Output

The input is done by performing some type of action (clicking the mouse or typing on a keyboard). The operating system then tells the hardware or software what to do with that input. This is processing. The computer then changes what you see on screen or plays a sound, or both together to generate the output.

##### Breaking Down the Process
The more you understand about the interactions between the steps of the computing process, the better you can troubleshoot when something goes wrong. *This is the core rule to being a great tech*.

##### Computing Software

###### Common Operating System Functions
The OS communicates, or provides a method for other programs to communicate, with the hardware of the PC or device. Operating systems also run on specific hardware. There are distinct versions of operating systems known as 32-bit and 64-bit. 64-bit is becoming more and more common today.

1. The OS creates a user interface
2. The OS enables users to determine the available installed programs and run, use, and shut down the programs of their choice
3. The OS enables users to add, move and delete the installed programs and data
4. The OS provides a method to secure a system from all sorts of threats, such as data loss or improper access

##### File Structures and Paths
Basically every operating system stores files in folders that are then organized in a tree pattern. The root of the tree is the drive or disk, followed by a folder, sub-folders and so on.

###### Windows
Windows contains important folders that help organize programs and documents. These sit in what's known as the *root directory*, which is where the OS is installed. Files are comprised of two pieces, the filename, and then the file extension at the end. The extension tells Windows what program to use to open the file. The combination of using a file extension with a program to open is called *file association*. 

###### C:\Program Files
Most programs on Windows install some or all of their essential files into a subfolder of the Program Files folder. If you installed a program it should have its own folder stored under here. 

###### C:\Program Files (x86)
The 64-bit editions of Windows creates two directory structures for program files. The 64-bit applications go into the C:\Program Files folder, where the 32-bit applications go into the C:\Program Files (x86) folder. This distinction makes it easy to find the right version of the application you are looking for.

##### Tech Utility Launch Points

###### Windows
***Settings*** provides a central location and a consistent interface for most of the tech tools used in Windows by administrators. Settings is slowly taking over most administrative functions that were handled by the Control Panel.

The ***Control Panel*** handles many of the maintenance, upgrade, and configuration aspects of Windows. It opens in Category view by default. *Administrative Tools* (also called Windows Tools in Windows 11), is one example of the powerful utilities found in the control panel. Administrative Tools allows you to setup hard drives, manage devices, test system performance, and much more.
Many programs, called *applets*, populate the Control Panel. All versions of Windows contain applets that enable you to control specific aspects of Windows, like the appearance, installed applications, and system settings.

##### How CPUs work

###### Registers
Registers are places on the CPU for instructions to be stored and processed as part of a clock cycle.

The CPU processes instructions through these registers one line at a time, and all of the commands for a given CPU are known as that CPU's *instruction set*.

###### Clock
A clock cycle happens by applying voltage, usually more than once, to a special wire on a CPU known as a *clock wire*. A single charge applied to this wire is known as a *clock cycle*. 

The *system crystal*, which is a quartz oscillator soldered to the motherboard, determines the speed at which the CPU and the rest of the PC components operate at.

##### Memory
Devices that hold bits (ones and zeroes) that the CPU needs to access at any given time are known generically as *memory*. Memory needs to not only store programs, but data as well. These devices need to be able to access any line of a program that the CPU needs to process, and at the same or similar speed to the clock cycles of a CPU. This memory is known as RAM (*random access memory*). RAM transfers data to and from the CPU in byte-sized chunks. When talking about quantities of bits, here are the different sizes and their corresponding terms:

1. Individual 1 or 0 - bit
2. 4 bits - a nibble
3. 8 bits - a byte
4. 16 bits - a word
5. 32 bits - a double word
6. 64 bits - a paragraph or quad word

Computers use *DRAM* (dynamic RAM) for main system memory. Dynamic RAM requires a constant charge, as well as continual refreshing of the circuits, otherwise the data gets lost. 

###### Address Bus
There is a special chip known as the *MCC* (Memory Controller Chip), that can grab any discrete byte of RAM that the CPU needs to process and act on. To accomplish this process, a second set of wires are attached to the CPU that allow it to directly communicate with the MCC. This set of wires is called the *address bus*.

#### 1101

##### DDR3 RAM
DDR3 RAM boasted higher speeds, more efficient architecture and about 30 percent lower power consumption compared to DDR2 RAM. DDR3 RAM uses a 240-pin DIMM. DDR3 SO-DIMM modules for laptops used 204 pins.

***Exam Tip*** - The CompTIA A+ 1101 exam will be challenging you on the different characteristics of the different types of RAM, including pin counts and transfer speeds if applicable.

In addition to having a 8-bit buffer for bandwidth, some DDR3 modules also included a feature known as XMP (Xtreme Memory Profile) for overclocking RAM.
Some motherboards that support DDR3 also support some features called *triple-channel* ,or *quad-channel* memory architecture. 

***Exam Tip*** - Make sure you are familiar with single-, dual, triple and quad channel memory architectures
##### DDR4
DDR4 memory arrived in late 2014 with slow adoption, although it is now considered the mainstream channel memory architecture now. DDR4 offers higher density and lower voltages than DDR3, and can handle faster data transfer rates. DDR4 uses a 288-pin DIMM, so they are not backwards-compatible with DDR3 slots.

##### DDR5
DDR5 arrived in 2020, and it came with all of the previous upgrades from previous modules, including doubled bandwidth, decreased power consumption and quadrupled DIMM capacity. The highest recorded available bandwidth at the time of the book's writing was 7200 MT/s. Power management on RAM is handled via an onboard circuit known as a PMIC (power management integrated circuit). This is different for DDR5, as DDR4 and below were all handled by the motherboard.

###### Latency
Different types of RAM respond to electrical signals at varying rates. When the memory controller starts to grab a line of memory, a slight delay occurs. After that RAM sends out the requested line of memory, there is another slight delay before the memory controller can ask for another line. This delay in response time is called *latency*. If two types of RAM have the same speed rating, RAM with a lower latency (like CL17) is a little faster than RAM with a higher latency (like CL19) because it responds more quickly. The CL refers to clock cycle delays. Because it's measured in clock cycles, CL is relative to the clock speed of the RAM.

Today's PCs that need to watch for RAM errors use a special type of RAM called *error correction code RAM* (ECC). ECC detects and corrects any time a single bit gets flipped, on the fly. It can detect, but *not correct* a double-bit error. 

###### Registered and Buffered Memory
The terms *Registered RAM*, or *Buffered RAM*, each refer to a small register installed on some memory modules to act as a buffer between the DIMM and the memory controller. This little piece of circuitry helps compensate for some electrical problems that crop up in systems with a lot of memory, like servers and high-end workstations.

A motherboard will always either use unbuffered memory, or buffered memory, but not both together.

###### Virtual Memory
Computers set aside a portion of the hard drive as an extension of system RAM that is known as *virtual memory*. The operating system saves this dedicated drive space as a page file, or a swap file. This is only used when the physical RAM in the system is maxed out and there are other programs that need to be opened by the OS. 

###### Installing DIMMs
When installing memory, your motherboard should detect and automatically set up any DIMM that you install, assuming you have the right RAM for your system. This uses a technology called *serial presence detect* (SPD). The SPD chip stores all the information about your DRAM, including size, speed, ECC or non-ECC, registered or unregistered and other technical bits.

#### 1101
PC peripherals usually cannot connect directly to the CPU. To handle this, a *controller*, which is a chip that connects a certain device to the CPU, is in charge of the communication.
Getting the CPU to communicate with a controller starts with a physical interconnection - a communication bus (wires) that enables the CPU to send commands to and from devices.

Around 1990, chip manufacturers began to combine multiple controller chips into *chipsets* to reduce the chip count and standardize communication between devices and the CPU. Early boards like the Intel 430VX contained two paired chips known as a *northbridge* and a *southbridge*.

![[Intel VX430 Board.jpg]]

Chipsets were in pairs for years, roughly from 1990 to about 2010. Now, CPUs have controllers built into them, like the memory and display controllers. With all of these functions built directly into the CPU, almost all chipsets are now just a single chip, which Intel refers to as the PCH (*Platform Controller Hub*). In today's terms, it is still common to refer to the chip on the board as a chipset, even though it is just one chip.

The chipset extends the data bus to every device on the PC. The CPU then uses the data bus to move data to and from all the devices connected to the PC.

A codebook of commands that a certain controller references in order to perform actions in running memory is known as a *device driver*. A device driver is simply code sitting in the hard drive that is then loaded into memory as your system starts up. The OS then loads these device drivers on boot.

In order to perform certain tasks or load programs that don't require a hard drive controller or load an OS, we need what is known as *ROM*. Motherboards store all of the code for these special functions on a ROM chip. ROM chips are nonvolatile, meaning that information is still stored on them even after losing a flow of electricity, and they are also read-only, meaning that once you store a program on one of these chips, you have to go through a specific re-programming process to change it.

***Exam Tip*** - Programs stored on ROM chips -- flash or any other kind of ROM -- are known as *firmware*, as opposed to programs stored on dynamic media, which are collectively called *software*.

So we have a ROM chip, but we still need some firmware to perform certain functions... enter UEFI/BIOS!

##### UEFI
Modern systems use firmware programming known as *Unified Extensible Firmware Interface*. This is a programming standard that defines how we configure utilities that every system needs to run: device drivers, boot support and system setup -- all on the motherboard's flash ROM chip.
The correct terminology for UEFI "device drivers" is *services*. 

***Exam Tip*** - The CompTIA A+ 1101 objectives list the term BIOS/UEFI, so if you see a question referring to BIOS, think UEFI

#### CMOS and the System Setup Utility
Every UEFI needs a tiny amount of writable memory. How much RAM does UEFI need? This writable memory is a small amount of RAM hooked up to a small battery to keep it working when the PC is off and unplugged. We call this memory *complementary metal-oxide semiconductor* (CMOS). Today the CMOS is built into the chipset, but earlier on it used to be a dedicated chip.

Every UEFI comes with a *system setup utility* that enables you to access and modify CMOS data. This utility usually requires different key presses in order to access it. This can be F2, F10, F12, or even the delete key.

#### Power-On Self Test (POST)
The BIOS is not the only program on system ROM. Every time the computer is turned on, it initiates a special program known as the *power-on self-test* (POST). This program performs a check of the system by sending out a command to all of the connected devices to essentially run a self-diagnostic. 

So how does a computer let you know when something went wrong during POST? Either via *beep codes*, or a *text-based message*.

#### The Boot Process
All PCs need a process to begin their operations. Once you feed power to the PC, the tight interrelation of hardware, firmware, and software enables the PC to start itself, or boot itself. This process is known as *bootstrapping*. 

When you first power on the PC, the power supply circuitry tests for proper voltage, then sends a signal down to a special wire on the CPU called the *power good wire*. Once this signal is sent and everything checks out, the CPU then sends a built-in memory address via its address bus. This special address is the first line of the POST program on the system ROM.

Almost all storage devices can be configured to boot an operating system by setting aside a specific location on the disk known as the *boot sector*. If the device is bootable, the boot sector will tell the system where to locate the OS. This is what happens for older BIOS systems

For newer UEFI-based systems, POST will hand control of the process over to a *Boot Manager*, which checks the boot configuration, and then loads the OS boot loader directly. UEFI firmware stores both the Boot Manager and boot configuration.

# Wisdom Extraction

**Understanding Firmware, UEFI, BIOS, and Related Components**

Firmware is essentially software embedded into hardware, stored in nonvolatile memory chips like ROM. It operates independently of an operating system, performing essential tasks before the OS loads.

1. **ROM and Firmware**: 
   - ROM (Read-Only Memory) stores firmware, which is crucial for initializing hardware components. Unlike software, firmware cannot be easily altered without specific tools or processes.

2. **BIOS and UEFI**:
   - BIOS (Basic Input/Output System) was traditionally stored on a separate chip but has been largely replaced by UEFI (Unified Extensible Firmware Interface). UEFI provides a standardized programming interface for modern systems, enabling configuration of device drivers and boot support through the motherboard's flash ROM.

3. **CMOS**:
   - CMOS (Complementary Metal-Oxide Semiconductor) is a small amount of writable memory integrated into the chipset. It stores system settings like boot order and disk priorities, accessible via a system setup utility accessed through keys like F2 or F10.

4. **POST (Power-On Self Test)**:
   - POST performs diagnostic checks upon booting, using beep codes or text messages to indicate hardware issues if detected during the initial startup sequence.

5. **Boot Process**:
   - Upon power-on, the CPU triggers a POST program from ROM. UEFI systems utilize a Boot Manager to locate and load the OS from the boot sector or Boot Manager settings, enhancing flexibility over traditional BIOS booting.

6. **Device Drivers in UEFI**:
   - Unlike traditional device drivers, UEFI uses "services" that any compatible device can utilize, promoting system consistency and flexibility across different hardware components.

7. **Exam Tips**:
   - Key terms include distinguishing firmware from software, recognizing BIOS/UEFI terminology, understanding CMOS functionality, and knowing POST symptoms for troubleshooting.

In summary, firmware is the low-level software crucial for initial hardware operations, with UEFI replacing traditional BIOS, providing a standardized approach through CMOS settings and services. The boot process, guided by POST, ensures hardware readiness before OS initialization.

The motherboard provides the foundation for the personal computer. It contains the wires -- called *traces* -- that make up the different data buses of the system. It also holds the vast majority of the ports used by the peripherals, and distributes power from the power supply.

#### How Motherboards Work
Three variable and interrelated characteristics define modern motherboards: 
1. form factor
2. chipset 
3. components

The *form factor* determines the physical side of the motherboard, as well as the general location of components and ports. The *chipset* defines the type of processor and RAM the motherboard requires and determines to some degree the built-in devices the motherboard supports, including expansion slots. Finally the built-in components determine the core functionality of the system.

#### Layers of the PCB
Most if not all modern motherboards are layered *printed circuit boards* (PCBs), which is copper etched onto a nonconductive material and coated with some sort of epoxy for strength. Every motherboard is four or more layers thick, and the layers contain a veritable highway of wires, which carry data and commands back and forth between the CPU, RAM and the various peripherals.
The layered structure enables multiple wires to send data without their signals interfering with each other.

Motherboard form factors are industry-standardized shapes and layouts that enable motherboards to work with various cases and power supplies. The power supply and the motherboard need matching connections, and different form factors define these different connectors.

##### ATX Form Factor

For example, the position of the power supply creates better air flow, the CPU and RAM are placed to provide easier access to those components, and the rearrangement of components prevents collisions with the CPU or northbridge.

##### Chipset
Because the chipset facilitates communication between the CPU and other devices in the system, its component chips are relatively centrally located on the motherboard. Different chipsets offer support for many different hardware options, including memory slot types, number and versions of USB ports, various mass storage devices, integrated network connections, video support and much more.

![[Intel_Z690_Chipset_Diagram.png]]

Good technicians need to know the hot chipsets in detail. The chipset defines almost every motherboard feature short of the CPU itself. 

##### Structure and Function of the Expansion Bus
Every device in the computer, whether soldered to the motherboard, or snapped into a socket -- connects to the external data bus and the address bus. *Expansion slots* are no exception. The connect to the rest of the PC through the chipset, but exactly where they connect *depends on the system*. More modern systems have the expansion slot connect directly to the CPU, but in older systems, they connected directly to the chipset.

Every chip in your computer has a CLK (clock) wire that needs to be pushed by a clock chip, which includes chips on your expansion cards. Instead of manufacturing a different device for all of the different listed motherboard speeds, IBM developed something known as a *expansion bus crystal*, which allowed expansion cards to run at their own dedicated speed separate from the rest of the components. This crystal controlled the part of the external data bus connected to the expansion slots.

Now let's cover the different iterations of the expansion slots, starting with ***PCI***.

##### PCI
Intel introduced *Peripheral Component Interconnect* in the early 1990s, and the PC expansion bus was not the same again. It provided a wider, faster and more flexible alternative than any other existing expansion bus. 

##### PCI Express
*PCI Express* (PCIe) is still PCI at its core, but it uses a point-to-point serial connection instead of PCI's shared parallel communication. PCIe devices have their own direct connections to the CPU, so they do not have to wait for other devices. Plus, this serial connection really comes in handy when you are dealing with really fast data transfer rates. A singular point-to-point serial connection is much faster than a shared 32-wire parallel connection.

PCIe connections use one wire for sending and another for receiving. Each of these pairs of wires between a PCIe controller and a device is known as a *lane*. Each direction of a lane runs at 2.5 gigatransfers per second. Each point-to-point connection can use 1, 2, 4, 8, 12, or even 16 lanes to achieve a maximum theoretical bandwidth of 256 GTps. The *transfer rate* describes the number of operations happening per second.

***Exam Tip*** - Make sure to know the various motherboard expansion slots for the CompTIA A+ 1101 exam.

There are a few common factors techs need to be aware of that can affect how these expansion slots perform:
1. ***The slot may be wired for fewer lanes that its size suggests***. You will most often see this where a x16 slot is wired up to only 4 or 8 lanes. If you put a video card that expects 16 lanes in a slot like this, it will only work at a fraction of its capacity.
2. ***Some motherboards don't have enough lanes for each slot to use its maximum at the same time***. In this case, adding expansion cards to a system might slow down already-connected devices.
3. ***Lower PCIe versions have less bandwidth available -- and some motherboards support different PCIe versions on different slots***. The CPU you select can also dictate the effective PCIe version.
4. ***PCIe lanes can be used for some other things on the board as well, and their speed/functionality can be affected by the number of slots/lanes in use***. 

There is not one great way to know exactly how each slot will perform.

***Exam Tip*** - Make sure you know the proper installation process for expansion cards, which is these four steps: knowledge, physical installation, device drivers and verification.

#### Understanding Electricity
The pressure of the electrons in the wire is known as *voltage* and is measured in units of Volts. The number of electrons moving past a certain point on a wire is known as the *current, or amperage* which is measured in units called *amperes*. The amps and volts needed for a certain device to function is expressed as *wattage*. The correlation between volts, amperes and watts is expressed as follows:

$$
V X A = W
$$
Volts X amps = wattage

Wires of all kinds also have a slight resistance to the flow of electrons. Resistance is measured in *ohms*.

*Circuit Breakers* are heat-sensitive or electromagnetically operated electrical switches rated for specific amperages. A *ground wire* provides a path of least resistance for electrons to flow back into the ground in the event of an overflow.

Electricity comes in two main flavors: *direct current (DC)*, in which the electrons flow in one direction around a continuous circuit, and *alternating current (AC)*, where the flow of electrons alternates back and forth in a circuit.

#### 1101

##### Powering the PC
PCs use DC voltage, so some conversion process has to take place before the PC can use AC power coming from the power company.

###### Supplying AC
In the United States, standard AC comes in somewhere between input 110 and 120 volts, often expressed as ***~115 VAC***. The majority of the rest of the world uses 230 VAC, so modern power supplies are designed to support both voltages through a feature called *dual voltage*. 

###### Testing Your Power Source
Before plugging in any critical components to an AC outlet, have some kind of device on hand for testing the outlets, like a *multimeter*. IEC-320 (standard wall outlet) plugs have three holes, called hot, neutral, and ground. These names describe the function of the wires that connect to them behind the wall plate. Neutral wires carry no voltage, but they complete the circuit by returning electricity to the local source, like a breaker panel. Ground wires make it possible for excess electricity to return safely to the ground.

When testing AC power, you want to check for three things:
1. The hot outputs approximately 115 V (or whatever the proper voltage is)
2. The neutral connects to the ground (0 V)
3. The ground wire connects to ground.

#### 1102

***Exam Tip*** - Make sure you are familiar with the technology and use of both surge protectors and battery backup systems for the CompTIA A+ 1102 exam.

#### 1101

##### Supplying DC
Once you have ensured the supply of good AC electricity for the PC, the power supply unit takes over, converting AC into several DC voltages, mainly 12V, 5V, and 3.3V. The PC uses the 12-V current to power motors on devices like hard drives, and it uses the 3.3 and 5-V current for supporting onboard electronics.

ATX did a great job supplying power for more than a decade, but over time more powerful CPUs, multiple CPUs, video cards and other components began to need more power that what the original ATX standard provided. Enter the updated standards for ATX: ATX12V 1.3, EPS12V, multiple rails, ATX12V 2.0, other form factors and active PFC

###### ATX12V 1.3
This came out in 2003, and introduced a 4-pin motherboard power connector known as the *P4 power connector*. This supplies more 12-V power to assist the original 20-pin power connector for ATX.

###### EPS12V
An industry group known as the Server System Infrastructure (SSI) developed a non-ATX standard motherboard and power supply known as *EPS12V*. This power supply came with a 24-pin main motherboard power connector, but it offered more current and stability for server motherboards. It also included an AUX connector, an ATX12V P4 connector, and a unique 8-pin connector.

###### Rails
Usually, the PCs power comes from a single transformer that takes the AC current from a wall socket and converts it into DC current that is split into three primary DC voltage rails: 12-V, 5-V and 3.3-V. Groups of wires run from each of these voltage rails to the various connectors, and each rail has a maximum amount of power it can supply. In a *single-rail* system, a single OCP (Over-current protection) circuit monitors all of the pathways. In a *multi-rail* system, each pathway got its own OCP circuit.

###### ATX12V 2.0
This standard incorporated some ideas from earlier standards, including a 24-pin connector. ATX12V 2.0 requires 2 12-V rails for any power supply rated higher than 230 W.

###### Niche-Market Power Supply Form Factors
There are some specialty power supply form factors out there that might be worth knowing about:
1. Mini-ITX and microATX - Smaller power supplies designed for these respective case form factors
2. TFX12V - A small power supply form factor optimized for low-profile ATX systems
3. SFX12V - A small power supply form factor optimized for systems using FlexATX motherboards

###### Active PFC
Good PC power supplies come with something known as *active power factor correction* (active PFC), which is extra circuitry that smooths out power coming from the wall before passing it to the main power supply circuits. This smoothing process eliminates harmonics.

##### Wattage Requirements
Every device in a PC will require a certain wattage to function. The total wattage of all devices combined is the ***minimum*** you will need the power supply to provide. If the power supply cannot produce the wattage that a system needs, that PC will not work properly or at all. Something to keep in mind is that ***no power supply can convert 100 percent of the AC power coming from the power company into DC current***. That difference gets lost in heat generation. 

Power supplies are typically graded for their efficiency under a standards program known as *80 Plus*. More efficiency can tell you how many watts the system draws to supply power to the PC in actual use.

***Exam Tip*** - The CompTIA A+ 1101 exam does not require you to figure out the precise wattage needs for a certain system. However, when building out a PC for a client, you do need to know this information!

#### How Hard Drives Work

##### Hard Disk Drives
A traditional *hard disk drive* (HDD) is comprised of individual disks, or *platters*, with read/write heads on actuator arms controlled by a servo motor -- all contained in a sealed case that prevents contamination by outside air.
The aluminum platters are coated with a magnetic medium. Two tiny read/write heads service each platter, one to read/write on top of the platter and the other to read/write on the bottom of the platter. Each head has a bit-sized *transducer* to read or write to each spot on the drive. 

##### Spindle (or Rotational) Speed
Hard drives rotate at a set *spindle speed*, with the spinning platters measured in *revolutions per minute* (RPM). The faster the speed, the faster the drive can store and retrieve data. 

##### Form Factors
Hard disk drives are manufactured in two standardized form factors, 2.5-inch and 3.5-inch. The form factor only defines size.

#### Solid-State Drives
SSDs use flash-memory chips to store data instead of spinning platters. These come in three form factors: the 2.5 inch, and two other flatter form factors known as *mSATA* and *M.2*. These last two form factors connect to specific slots on motherboards. M.2 slots come in a variety of what are known as *keyed configurations*, which are different applications of mass storage usage. 

![[M.2_Slots_and_Key_Variations.png]]

It is important to know the differences between the above-listed variations.

The most common size dimensions for M.2 SSDs are 2242, 2260, 2280, and 22110. Longer drives are able to accommodate more flash memory chips, which allows for greater storage capacity.
SSDs also use nonvolatile flash memory like *NAND* that retains data when power is turned off or disconnected.
SSDs operate internally by writing data in a scattershot fashion to high-speed flash memory cells in accordance with the rules contained in the internal SD controller.

#### Connecting Mass Storage
Setting up communication between a CPU and a mass storage drive requires two main items. First, there must be standardized physical connections between the CPU, the drive controller and the physical drive. Second, the CPU needs to use a standardized protocol, so it knows how to speak to the mass storage device.

Luckily for A+ techs, mass storage standards have been defined for the past 25 years, with the most important being *ATA/ATAPI*.

The *Advanced Technology Attachment* standards started with version 1 back in 1990, but only two version are of interest to us: PATA and SATA. *Parallel ATA* was introduced with ATA/ATAPI version 1. *Serial ATA* was introduced with version 7.

##### PATA
PATA drives are recognized by their data and power connections. These drives used unique 40-pin ribbon cables, and they plugged directly into a system's motherboard. All PATA drives used a standard Molex power connector.

![[PATA_Drive_Connection.png]]

***Exam Tip*** - CompTIA may ask about IDE cables and Molex power connectors, so be sure to familiarize yourself with them for the exam.

##### SATA
SATA creates a point-to-point connection between the SATA device -- magnetic hard drives, solid-state drives, optical media drives -- and the SATA controller, known as the *host bus adapter (HBA)*. Because SATA devices sent data serially instead of parallel, the SATA interface needed far fewer physical wires -- only 7 connectors instead of the typical 40 for PATA.

***Exam Tip*** - The CompTIA A+ 1101 exam refer to the 40-pin PATA ribbon cable as an IDE cable. They are the same thing, so be sure to look out for this on the test.

*External SATA (eSATA)* extended the SATA bus to external devices, as the name implies. eSATA drives used connectors that looked similar to internal SATA connectors, but they were keyed differently. Below is an example of an eSATA connector on a motherboard:

![[eSATA_Connector.png]]

External SATA used shielded cable in lengths up to 2 meters outside the PC and was hot-swappable.

***Exam Tip*** - eSATA took a back seat when USB 3.0 hit the market. You will only find it on very old systems, drive enclosures and on the CompTIA A+ exam.

##### Refining Mass Storage Communication
The original ATA standard defined very specific commands for the CPU to communicate with the drive controller. The two most commonly used command sets are AHCI, and NVMe.

###### AHCI
Current versions of Windows support the *Advanced Host Controller Interface (AHCI)*, which is an efficient way to work with SATA HBAs. AHCI unlocks some features of SATA like native command queuing and hot-swapping. 
*Native Command Queuing (NCQ)* is a disk-optimization feature for SATA drives. It uses the SATA interface to achieve faster read and write speeds than were possible with PATA. 

***NOTE*** - while SATA supports the ability to hot-swap drives, ***the motherboard and operating system must also support this!***

###### NVMe
For an SSD to work with the operating system, the SSD has to include some circuitry that the OS can see that makes the SSD appear to be a traditional spinning drive. Once a read or write operation is commenced, the virtual drive circuits pass the operation through a translator in the SSD that maps the guts of the SSD.

The *Non-Volatile Memory Express (NVMe)* spec supports a communication connection between the OS and the SSD directly through a PCIe bus lane, which reduces latency and takes full advantage of the fast speeds of high-end SSDs.

#### Protecting Data with RAID

##### SCSI
There is a particular drive technology known as *small computer system interface (SCSI)* that currently dominates in the server market. SCSI devices use a standard SCSI command set, meaning you can have both old and new devices connected and they can communicate without any problems.
*Serial Attached SCSI (SAS)* hard drives provide fast and robust storage for servers and storage arrays today. SAS-4, which is the latest SAS interface, provides speeds of up to 22.5 Gbps.

***Exam Tip*** - The CompTIA A+ exam objectives list SCSI as a type of hard drive cable, but that only means SAS.

You want to make sure your critical data is protected, backed up and easily restorable if possible. There are many ways to accomplish this with drives, and two of those methods are *disk mirroring*, where you write the same data to two drives at a time. Another method that is like mirroring is *disk duplexing*, where each drive has its own controller that handles the reading and writing of the duplicate data to the drives. 

You can also use multiple hard drives to increase your access speed. *Disk striping* spreads out the data among (at least) two drives. *Disk striping with parity* protects data by adding extra information, called *parity data* that can be used to rebuild the original data set if one of the drives fails.

##### RAID
RAID stands for *Redundant array of independent disks*. An *array* describes two or more drives working together as a unit. Multiple different types of RAID are still in use today, and they are all broken down below: 0, 1, 5, 6, 10, and 0+1
1. ***RAID 0 - Disk Striping***: This requires at least two drives and does NOT provide data redundancy. This is known as *scary RAID* because if just one drive fails, all data is lost.
2. ***RAID 1 - Disk mirroring/duplexing***: RAID 1 arrays require at least two hard drives, although they can work with any even number of drives. This is the ultimate in data safety, but you will lose storage space because of the duplicated data.
3. ***RAID 5 - Disk striping with distributed parity***: RAID 5 distributes data and parity information evenly across all drives. This is the fastest way to provide data redundancy. RAID 5 also requires a minimum of three drives.
4. ***RAID 6 - Disk striping with extra parity***: If you lose a hard drive in a RAID 5 array, your data is at risk until you replace the bad drive and rebuild the array. RAID 6 is RAID 5 with extra parity information. RAID 6 will need at least 4 drives, but the tradeoff is that you can lose up to two drives at the same time.
5. ***RAID 10 - Nested, striped mirrors***: Requiring a minimum of four drives, RAID 10 is accomplished by creating a pair of RAID 1 arrays. The arrays look like single drives to the OS, and now, with this configuration, we can block stripe across the mirrored pairs!
6. ***RAID 0+1 - Nested, mirrored stripes***: Like RAID 10, RAID 0+1 is a nested set of arrays that works in opposite configuration from RAID 10. It takes a minimum of four drives to implement RAID 0+1.

***Exam Tip*** - Make sure that you are familiar with the different RAID levels, 0, 1, 5, 10. Know the minimum number of drives in a given level array, and how many failures a given array can withstand while still remaining functional.

### Understanding RAIDs and Their Benefits

RAID (Redundant Array of Independent Disks) is a method of using multiple hard drives to improve performance, provide redundancy, or both. Below is an overview of the different RAID levels and their purposes:

1. **RAID 0 - Disk Striping**:
   - **Minimum Drives**: 2
   - **Purpose**: Increases I/O throughput and improves access times.
   - **Redundancy**: None (data loss possible if one drive fails).

2. **RAID 1 - Disk Mirroring/Duplexing**:
   - **Minimum Drives**: 2
   - **Purpose**: Provides data redundancy by duplicating data across two drives.
   - **Redundancy**: High (no data loss unless both drives fail).
   - **Storage Loss**: Data storage is doubled because each drive holds identical data.

3. **RAID 5 - Disk Striping with Distributed Parity**:
   - **Minimum Drives**: 3
   - **Purpose**: Combines striping and parity checking to provide redundancy.
   - **Redundancy**: High (data loss possible if one drive fails, but it can be rebuilt from existing data).
   - **Storage Loss**: Data is distributed across all drives with parity information.

4. **RAID 6 - Disk Striping with Extra Parity**:
   - **Minimum Drives**: 4
   - **Purpose**: Similar to RAID 5 but provides additional redundancy by allowing up to two simultaneous failures.
   - **Redundancy**: Very high (can withstand up to two drive failures).

5. **RAID 10 - Nested, Striped Mirrors**:
   - **Minimum Drives**: 4
   - **Purpose**: Combines RAID 1 and RAID 0 for better performance and redundancy.
   - **Redundancy**: High (can withstand up to two drive failures).
   - **Storage Loss**: Data is duplicated in a mirrored setup, which can be striped across the array.

6. **RAID 0+1 - Nested, Mirrored Stripes**:
   - **Minimum Drives**: 4
   - **Purpose**: Similar to RAID 10 but mirrors the striped data.
   - **Redundancy**: High (can withstand up to two drive failures).

### Software vs. Hardware RAID

- **Software RAID**: Utilizes the operating system's capabilities to manage RAID configurations. It is commonly used in consumer-grade systems and offers flexibility but may be slower compared to hardware-based solutions.

- **Hardware RAID**: Uses dedicated controllers that handle all RAID functions, often with their own processors and memory. These controllers can provide faster performance and additional features like hot-swapping.

### Choosing the Right RAID Level

Selecting the appropriate RAID level depends on your requirements for redundancy, storage capacity, and performance:

- **For Maximum Redundancy**: RAID 1 or RAID 6 are ideal.
- **For High Performance with Some Redundancy**: RAID 10 is a good balance between performance and data protection.
- **For Cost-Efficiency**: Consider RAID 5 if you need redundancy without excessive cost.

### Summary

RAID provides multiple benefits, including data redundancy, improved performance, and storage flexibility. Understanding the different levels and their trade-offs allows you to make informed decisions for your specific needs. Whether you opt for software or hardware RAID, ensure that it aligns with your system's requirements and performance goals.

#### Hard Drive Partitions
Before a magnetic disk drive leaves a factory, it is magnetically preset with millions of storage areas called *sectors*. Modern drives today use 4096-byte Advanced Format (AF) sectors.

Solid-state drives come from the factory with each NAND chip storing millions of 4096-byte storage areas called *pages*. A group of pages can then combine into what is known as a *block*. 128 pages per block is around the average size, but the size of a block can vary.
The CPU and OS never talk to these internal structures. Instead, the controller on the drive itself uses *logical block addressing* (LBA) to present all of these storage chunks as nothing more than a number that starts at LBA0, and then goes until every sector or page has an LBA number.

LBA makes addressing any form of mass storage easy, and that is how the OS interacts with mass storage, through blocks. The first step in this organization and communication process is *partitioning*. Partitioning is the process of dividing up a hard drive into one or more logical chunks that can then be formatted with a file system for mass storage.

#### 1102
Windows supports three different partitioning methods: the older master boot record (MBR), Windows' proprietary dynamic storage partitioning scheme, and the GUID partition table (GPT).

##### Master Boot Record
The first sector of an MBR hard drive contains what is called the *master boot record* (MBR). This is simply code that informs the system about any and all installed OSes. The master boot record also contains a *partition table*, which describes the number and size of partitions on the disk. The instructions in the MBR use this table to determine which partition contains the active operating system.

After the MBR locates the partition, the *partition boot sector* loads the OS on that partition.

***Exam Tip*** - Only one master boot record and one partition table within that master boot record exist per MBR disk. Each partition has a partition boot sector.

MBR partition tables support two types of partitions: primary and extended. *Primary partitions* are designed to support bootable operating systems. *Extended partitions* are not bootable.

###### Primary Partitions and Multiple Operating Systems
Primary partitions are assigned drive letters that appear in the File Explorer in Windows. The first lettered partition in Windows is always C:. After that, you can label partitions with D: through Z:. ***Only primary partitions can boot operating systems.***

To control any multiboot setups, many people use a free Linux-based boot manager called Grand Unified Boot Loader (GRUB). When the computer boots, the boot manager software yanks control from the MBR and asks which OS you want to boot from.

##### Dynamic Disks
With Windows 2000, Microsoft defined a type of partitioning called *dynamic storage partitioning*, otherwise known as *dynamic disks*. Microsoft calls a drive structure with a dynamic disk a *volume*. When you create a dynamic disk, you can create as many volumes on it that you would like. You are not limited to just four partitions.

##### GUID Partition Table
The *GUID Partition Table* (GPT) scheme shares a lot with the MBR scheme, but overcomes many of MBR's limitations. Here are the big improvements:
1. A GPT drive can have an almost unlimited number of partitions on it. Windows has limited this value to 128.
2. GPT partitions have a much larger size restriction, measured in zettabytes.

Instead of the old master boot record and partition table, GPT drives use a GPT header and a partition entry array. Both are located at the beginning and end of a drive so there is a protected backup copy.

##### When to Partition
Partitioning is not usually a task you have to do for an already setup system. The two most common scenarios for when you might need to partition a drive are when you install a new operating system, and when you add a new drive to an existing system. One of the new tools Windows provides is the ability to resize partitions nondestructively by shrinking or expanding them with available free space.

##### Hard Drive Formatting
Once the drive has been partitioned, it needs to be formatted with a file system. A *file system* is an organization of all the blocks contained in that partition, which enables file storage and retrieval.  Formatting also creates a root directory to enable the partition to store folders. Every operating system has its own file systems. For Apple, they use APFS. Linux users mainly use ext4, but there are others like BTRFS, XFS, ZFS and so on. Windows uses file systems like NTFS, FAT32 and exFAT.

##### File Systems in Windows
All Windows file systems organize blocks of data into groups known as *clusters*. The size of each cluster varies according to the file system and the size of the partition.

###### FAT32
The mapping of bad blocks is one of the functions of *high-level formatting*. After the format program creates the *file allocation table* (FAT), it marches through every block of the entire partition, writing and attempting to read from each block sequentially. If it finds a bad block, it places a special status code (0000FFF7) in the block's FAT location, which indicates that the cluster is unavailable for use. Formatting also marks the good blocks with 00000000

***Exam Tip*** - CompTIA may ask you how to recover a deleted file. If the file is still in the recycle bin, simply navigate to the recycle bin, right-click on the file, and then click Restore. If it is not in the recycle bin or already deleted from the bin, you will need to install an extra utility or a third-party utility to attempt recovery of that file.

##### NTFS
The Windows format of choice these days is *New Technology File System* (NTFS). NTFS uses clusters of blocks and file allocation tables similar to FAT32, but it is much more powerful and complex.

NTFS offers six major improvements and refinements: redunadancy, security, compression, encryption, disk quotas and cluster sizing.

###### NTFS Structure
NTFS uses an enhanced file allocation table called the *master file table* (MFT). When you defragment an NTFS partition, there is a small, immovable chunk somewhere on the drive near the front. That is the MFT.

###### Cluster Sizes
NTFS uses clusters like FAT32. The table below shows the default cluster sizes for NTFS:


| Drive Size    | Cluster Size |
| ------------- | ------------ |
| 7 MB to 16 TB | 4 KB         |
| 16 to 32 TB   | 8 KB         |
| 32 to 64 TB   | 32 KB        |
| 64 to 128 TB  | 64 KB        |
| 128 to 256 TB | 128 KB       |

***Exam Tip*** - NTFS supports partitions from 16TB by default, but that can go up to 8 petabytes

##### Mounting Partitions as Folders
While partitions and volumes can be assigned a drive letter from D: through Z:, they can also be mounted as a folder on another drive, also known as a *mount point*. This lets you use existing folders to store more data than can fit on a single drive or partition/volume.

***Exam Tip*** - Disk Management is the go-to tool in Windows when adding drives or disk arrays to a system.

#### Storage Spaces

***Exam Tip*** - A storage pool is a collection of physical drives that enables you to flexibly add and expand capacity. Storage spaces are virtual drives that are created from storage pool free space. Storage spaces have resiliency and fixed provisioning.

#### USB Ports
*Universal Serial Bus* (USB) connects almost every type of peripheral one might consider today.

##### Understanding USB
The core of the USB is the *USB host controller*, which is an integrated circuit built into the motherboard chipset. The host controller acts as an interface between the system and every USB device that connects to it. Connected to the controller is a *USB root hub* which acts as the part of the controller that makes the physical connection to the USB ports. Every USB root hub acts like an expansion bus, meaning that they are buses themselves. 

A single host controller can support up to 127 USB devices, but real-life circumstances can severely limit this theoretical maximum. The host controller acts as the boss of any device that plugs into that controller. The host controller sends commands and provides power to the USB devices. The controller itself is *upstream*, controlling devices connected to it *downstream*. Because all of the devices connected to the controller share the connection, with each new device added, speed and power are reduced.

##### USB Standards and Compatibility
USB has been through a number of different revised standards. Here are the high points of each one:
1. USB 1.1 was the first standard and defined two speeds: Low-Speed USB running at 1.5 Mbps, and Full-Speed USB running up to 12 Mpbs.
2. The USB 2.0 standard introduced Hi-Speed USB running up to 480 Mbps
3. USB 3.0 is capable of speeds of up to 5 Gbps -- ten times faster than USB 2.0. It is also referred to as *USB 3.1 Gen 1*, but not on the CompTIA A+ exams.
4. USB 3.1 can handle speeds of up to 10 Gbps. This is also marked as *USB 3.1 Gen 2*.
5. USB 3.2 supports speeds up to 20 Gbps using a pair of 10 Gbps lanes.

### 1102

#### Registry
The Windows Registry is a critical database that stores everything about a PC, including information on all the hardware, network information, user preferences, network types, passwords, desktop color, pretty much everything you can find in Windows. Almost any form of configuration you do to a Windows system involves editing the Registry, and ***your system will not boot without a properly configured Registry***. 

##### Accessing the Registry
To access the Registry directly, type *regedit* in the Search bar from your desktop. You can also run regedit from the command line.

##### Registry Components
The Registry is organized in a tree structure similar to the folders on the file system. Once you open the Registry Editor, you will see five main subgroups, or *root keys*:
1. HKEY_CLASSES_ROOT
2. HKEY_CURRENT_USER
3. HKEY_LOCAL_MACHINE
4. HKEY_USERS
5. HKEY_CURRENT_CONFIG

When you open one of these root keys, you will see subkeys underneath them. A subkey can also contain other subkeys, which are known as *values*. 

###### HKEY_CLASSES_ROOT
Historically, this key defined the standard class objects used by Windows. A *class object* is a named group of functions that defines what you can do with the object it represents. Everything that has to do with files on the system is defined by a class object.

###### HKEY_CURRENT_USER and HKEY_USERS
Windows is designed to support more than one user on the same system, storing personalized information such as desktop colors, screensavers and the contents of the desktop for every user account on that system. HKEY_CURRENT_USER stores the current user information, and HKEY_USERS stores all of the personalized information for each user on the system.

###### HKEY_LOCAL_MACHINE
This root key contains all of the data for a system's non-user-specific configurations. This encompasses every device and every program on your computer.

###### HKEY_CURRENT_CONFIG
If the values in the HKEY_LOCAL_MACHINE key have more than one option, this root key defines which one is currently being used.

##### Command-Line Registry Editing Tools
Windows includes a couple of command-line tools to edit the Registry. The two you might need on occasion are reg and regsvr32.

The *reg* command is a full Registry editing tool.  You can do things like view Registry keys and values, import and export some or all of a Registry, and even compare two different versions of a Registry. The *regsvr32* command can modify the Registry in only one way, adding dynamic link library files as command components in the Registry.

#### Your Basic Windows Toolset

##### System Configuration
To access the System Configuration menu, type *msconfig* in the search bar on the desktop. This utility offers many different features spread across the tabs listed below:
1. **General** - Select the type of startup you would like to use for the next boot. 
2. **Boot** - This tab contains advanced boot features. You can see every copy of Windows you have installed, set a default OS, or delete an OS from the boot menu. You can even setup a safe boot. A *safe mode* boot will load minimal, generic trusted drivers and is used for troubleshooting purposes.
3. **Services** - This is similar to the Services tab in the Task Manager. You can enable or disable any services running on the PC.
4. **Startup** - This tab lets you launch Task Manager to enable you to toggle on or off any startup programs.
5. **Tools** - This tab lists many of the tools and utilities available in Windows, including Event Viewer, Performance Monitor, Command Prompt, and so on.

###### Getting the Most out of the CLI

###### Shells
The command line, like a GUI, is another way to interface with a computer. The command line interprets input and sends it to the OS in the form of something the OS understands, and then it shows the results. The tool that interprets the command input is known as a *shell*.

***Exam Tip*** - The CompTIA A+ 1102 exam does not include Powershell for Windows, but it will be listed in this chapter because the basics are important to know. You will be quizzed more on commands you will find from a basic command prompt.

##### Accessing the Command Line Interface in Windows
Just type in *cmd* at the search bar, or search for command prompt in Windows. You can also launch the command prompt as an administrator if needed.

###### Accessing the Command Line in macOS and Linux
Linux and macOS both have very similar command lines that can be accessed through programs known as *terminal emulators*. You can type *terminal* in both the related macOS and Linux search functions to find a terminal emulator. These UNIX-based terminals allow you to run commands with what is known as *super user (sudo)* privileges. 

To enter a command as an admin on mac or Linux, precede your command with sudo, and then type the command. You may be prompted to enter a password for the administrator.

#### The Prompt
No matter what shell you use, the command line always focuses on a specific folder, aka your *current working directory*. Windows focuses on using Drive letters like C: to indicate what drive you are currently accessing, and then a folder path. Linux and macOS use just a / (forward slash) to indicate the root level directory.

### Mastering Fundamental Commands

#### Structure: Syntax and Switches
All commands in every command-line interface use a similar structure and you run them all the same way. You type the name of the command, followed by the target of that same command, then any modifications (switches) you want to apply, then you hit Enter. The proper way to write a command is known as command *syntax*. 

##### Teaching Yourself to Fish
To get help on commands and switches, you can use /? in Windows after the name of a command, and the *man* command in Linux to pull up the manual page for a command.

***Exam Tip*** - The CompTIA 1102 objectives mention the /? switch on Windows and the man command for Linux when it comes to getting help on commands.

### 1101

#### LCD Panels
A color LCD screen is composed of tiny liquid crystal molecules called *sub-pixels* arranged in rows and columns between polarizing filters. When electric current is applied to the liquid crystal molecules, they act as a shutter to enable light to pass through. A translucent sheet above the sub pixels is colored red, green or blue. Each group of these sub-pixels forms an individual *pixel*. 

The typical LCD monitor is composed of two pieces, an LCD panel to create the image, and a *backlight* to illuminate the image so you can see it. Some older models needed *inverters* to send power to backlights that required alternating current electricity. 

##### LCD Panel Technologies
The three most common panel types today used in LCD panels are *twisted nematic (TN), in-plane switching (IPS), and vertical alignment (VA)*. 

##### OLED Panels
OLED screens use organic compounds between the glass layers that light up when given an electrical charge. Since they emit their own light, they don't require backlights. OLED pixels can turn off completely, enabling a pure black and great contrast compared with LCD panels.

##### Projectors
*Projectors* generate an image in one device and then use the light to throw them onto a screen or some other object. 

###### Projector Image Technologies
Projectors display an image in one of two varieties, either through LCD, or *DLP (Digital Light Processing)*. DLP uses an array of tiny mirrors to project a front-view image. DLP projectors tend to produce better color and a softer image than LCD. They also tend to weigh less than their LCD counterparts.

###### Lumens
The brightness of a projector is expressed in *lumens*, a measure of the amount of visible light given off by a light source. If you use a projector in a small, dark room, 1000 to 1500 lumens should work well. If you use a projector in a mid-sized room with typical lighting, you will need at least 2000 lumens. Projectors for very large rooms have ratings of over 10,000 lumens and are very expensive.

###### Throw
A projector's *throw* indicates the size of the image at a certain distance from the screen. All projectors have a recommended minimum and maximum throw distance that you need to take into consideration. 

###### Light Sources
Most projectors use one of three light sources: powerful light bulbs, LEDs, or lasers.
*Lamps* - light bulbs that produce a lot of lumens in a small form factor - have been the standard for a long time. LED based projectors don't generate as much heat, and they typically have lifespans of around 30,000+ hours compared to lamps, which have about 3000 hours. Laser-based projectors produce vibrant, high-contrast images and are more expensive than competing technologies. Laser light sources can last around 20,000 hours.

### Common Display Features

#### Connections

##### VGA
*Video Graphics Array (VGA)* is pretty old and it uses a 15-pin, three row, D-type connector. VGA is the oldest and least-capable monitor connection type.
![[VGA_Connector.png]]

##### DVI
The *Digital Visual Interface (DVI)* standard helped build a bridge between the world of old analog displays and modern digital ones. DVI is actually three different connectors that look alike: DVI-D (Digital), DVI-A (analog), and DVI-I (interchangeable)

As a legacy standard, DVI appears on fewer and fewer new devices, but DVI-I connectors can still power low-end displays. *Single-link DVI* can drive a display with a resolution of 1920 x 1080 at a refresh rate of 60 Hz, and *dual-link DVI* can drive a 2048 x 1536 display at 60 Hz. 

![[DVI_Connections.png]]

##### HDMI
Many monitors connect to a computer via the *High-Definition Multimedia Interface (HDMI)* connector, which carries both video and audio signals. The latest version of HDMI can handle just about any resolution, but keep in mind that an old version may not.

![[HDMI_Connector.png]]

*Using DisplayPort (DP), Thunderbolt, and USB Type-C* connections are an increasingly common way to supply video and audio to displays.

Thunderbolt 1 and 2 adopted the same connector type that is used for the small version of DisplayPort, called Mini DisplayPort (mDP). Thunderbolt 3 and 4 however, use the USB-C connector type.

![[DisplayPort_Connector.png]]

Some projectors use a connection technology called *HDBaseT* tjat enables long-range connectivity for uncompressed HD video and audio over Cat 5 or Cat 6 network cables.

### Display Adapters
The video source for most monitors is a computer's display adapter (or graphics card). This device handles a number of video-related chores for the computer - though the most fundamental is processing information from the CPU and sending it to the display. 

#### Motherboard Slot
Every current discrete video card plugs into a PCIe slot on the motherboard. Many CPUs/motherboards have a built-in display adapter also, but we are just looking at PCIe for right now.

##### PCIe
The *PCI Express (PCIe)* interface was developed to replace the older PCI and *Accelerated Graphics Port (AGP)* interfaces. All PCIe videos cards use the PCIe x 16 connector. 

##### Graphics Processor
The graphics processor handles the heavy lifting of taking commands from the CPU and translating them into coordinates and color information that the monitor understands and displays.

##### Video Memory
Video memory can be a bottleneck in three different ways: data throughput speed, access speed and simple capacity. Manufacturers can address these limitations by upping the width of the bus between the video RAM and the video processor, adding more and more total RAM, and developing special-purpose RAM.

Specialized types of video RAM (VRAM) - namely Graphics DDR (GDDR) and High Bandwidth Memory (HBM) exist to meet these high speed and bandwidth demands. 

##### Integrated GPUs
Some motherboards support CPUs that have integrated GPUs built into them.

The guide also explains:

1. **Display Adapters**: The video source for most monitors is a computer's display adapter (or graphics card).
2. **Motherboard Slot**: PCIe slots on the motherboard.
3. **PCI Express**: A high-speed interface that replaced older interfaces like PCI and AGP.
4. **Graphics Processor**: Handles heavy lifting of processing commands from the CPU.
5. **Video Memory**: Can be a bottleneck in terms of data throughput speed, access speed, and capacity.

##### Talking Points of the Chapter

### 1101

#### Roles Hosts Play in Networks

The goal of networking is to connect computers so that they can share resources or access other shared resources.
To share and access resources, a network must have the following:
1. Something that defines and standardizes the design and operation of cabling, network cards and the interconnection of multiple computers
2. An addressing method that enables clients to find servers and enables servers to send data to clients, no matter the size of the network
3. Some method of sharing resources and accessing those shared resources

#### Networking Technologies
Both clients and servers need *network interface controllers (NICs)* that define or label the machine on the network. A NIC also breaks files into smaller data units to send across the network and reassembles the units it receives back into whole files. You also need some kind of medium for delivering the data units between two or more devices. Finally, a computer's operating system has to be able to communicate with its own networking hardware and with other machines on that network.

***Exam Tip*** - You are likely to see the term NIC on the exams, but the objectives will likely call them *network interface cards* instead of controllers.

##### Frames and NICs
Data is moved from one device to another in discrete chunks called *frames*. The actual NICs on the computers create and process these frames.
Every NIC in the world has a unique built-in identifier, an address specific to that card, known as a *media access control (MAC) address*. A MAC address is a 48-bit binary number, which can provide more than 281 trillion MAC addresses, so there are plenty to go around for a while.
MAC addresses are represented using 12 *hexadecimal* characters, with the hex numbering scheme being base 16, and going from 0-9, and then a-f for 10-15.

To understand MAC addresses, we need to first understand frames. First, frames contain the destination MAC address for the computer receiving the data. Second, we have the MAC address of the card for the computer that sent the data, aka the source. Thirdly, we have the data itself, which can vary in size depending on the type of frame. Finally, the frame tacks on a data check to ensure what is being sent is in good working order. This is known as an *FCS, or frame check sequence*. Frames use an algorithm known as the *cyclic redundancy check (CRC)* to add this sequence onto the end of a frame.

##### Ethernet
*Ethernet* is a series of defined networking standards written back in the 1970s that determine how computers communicate across all aspects of a network. The standard ethernet frame has not changed for a long time, and this is good, as it allows for communications between different hosts running different *ethernet flavors* to run just fine. Ethernet today runs at two main speeds, uses a star-bus topology and connects via a cable known as unshielded twisted pair (UTP). Those speeds are 1000BASE-T (Gigabit ethernet), and 10GBASE-T (10 Gbps).

##### The Ethernet Star Bus
With all ethernet networks, every individual host connects to a central box. You attach each system to this box via cables to special ports. This network layout is called a *star bus* topology. The term topology refers to the physical or logical layout of the network connections. 
The central box, the *switch*, provides a common point of connection for networked devices. The connection between a computer and a switch is known as a *segment*. With most cable types, ethernet segments are limited to *100 meters* or less.

###### Unshielded Twisted Pair (UTP)
UTP cabling is the specified cabling to 100/1000BASE-T as well as 10GBASE-T networks, and is the predominant cabling system used today. Twisted pair cabling consists of AWG 22-26 gauge copper wire twisted together into color-coded pairs. Each wire is individually insulated and encased as a group in a common jacket.

![[UTP_Ethernet_Cabling.png]]

UTP cables come in categories that define the maximum speed at which data can be transferred (also called *bandwidth*). The major categories (Cat) are listed in the table below:

| Cat 1  | Standard telephone line                                                                                                    |
| ------ | -------------------------------------------------------------------------------------------------------------------------- |
| Cat 3  | Designed for 10 Mbps networks                                                                                              |
| Cat 5  | Designed for 100 Mbps networks                                                                                             |
| Cat 5e | Enhanced to handle 1-Gbps and 2.5 Gbps networks at 100-meter lengths                                                       |
| Cat 6  | Supports 1-Gbps, 2.5 Gbps, and 5 Gbps networks at 100-meter segments; 10-Gbps networks at 55 meters                        |
| Cat 6a | Supports 10-Gbps networks at 100 meter segments                                                                            |
| Cat 6e | nonstandard term used by a few Cat 6 or Cat 6a manufacturers                                                               |
| Cat 7  | Supports 10-Gbps networks at 100-meter segments; shielding for individual wire pairs reduces crosstalk and noise problems. |

###### Shielded Twisted Pair (STP)
*Shielded twisted pair (STP)* has the wires surrounded by shielding to protect them from electromagnetic interference. Some STP cables are rated for *direct burial*. These cables will have a thicker jacket, and some waterproofing to make it suitable for direct burial underground.

#### Ethernet with Twisted Pair
1000BASE-T networks and up require cables with all 4 pairs of wires in Cat 5e and higher cables, and 10GBASE-T requires all four pairs in Cat 6 or higher. These cables use a connector known as an *RJ45* connector. One thing to keep in mind is that *RJ connectors also have Cat ratings just like the cables do, so make sure your cable AND connector match up!*
ANSI/TIA has two standards for connection an RJ45 connector to a UTP cable: *T568A* and *T568B*. Make sure that all of your cabling uses the same standard throughout, and *keep records* of your standard choice for cabling.

##### Ethernet with Alternative Connections

###### Fiber Optic
*Fiber optic cabling* uses light instead of electricity to transfer frames across a network. Many fiber ethernet networks use *62.5/125 multimode* fiber optic cable. This cabling requires two strands of fiber (one for sending and one for receiving). 

![[Fiber_Optic_Cable_Connectors.png]]

Fiber optics are considered *half-duplex*, meaning that data flows only one way, hence the need for two fibers to transmit and receive data. Light can be sent down a fiber optic cable in one of two ways: either through LEDs or lasers depending on the cable type.
LEDs are generally used with multimode cabling, while lasers are meant for single-mode fiber, which supports longer connection distances. If you want to use fiber optic cabling, you will need a fiber switch and fiber optic network cards.

###### Coaxial
Early versions of ethernet ran on *coaxial cable* instead of UTP. Coax is primarily used for cable modem and satellite connections.

![[Coaxial_Cable.png]]

Coax cables use an RG rating, and the only two you need to know for the exam are *RG-59* and *RG-6*. The RG rating should be visible on the cable itself. Coax also uses what's known as an *F-type connector*.

#### Implementing Ethernet

##### The Typical LAN
A *local area network (LAN)* is a group of computers located physically close to each other - no more than a few hundred meters apart at most. A group of computers connected by one or more switches is what's called a *broadcast domain*, which means that all nodes can receive broadcast frames from every other node.

***Exam Tip*** - For the CompTIA A+ exams, remember what a LAN is as defined above. Also remember that most if not all LANs are categorized as broadcast domains.

#### Structured Cabling
If you want a functioning, dependable, real-world network, you need a solid understanding of a set of standards that together form a concept called *structured cabling*. These standards define every aspect of a cabled network, from the type of cabling to use to the standards on running cable in walls and the position of wall outlets.
The idea of structured cabling is to create a safe, reliable cabling infrastructure for all of the devices that may need interconnection.

The very definition of structured cabling provides safety, protecting the star topology from vacuum cleaners, clumsy coworkers, and electrical interference. It would also have extra hardware to organize and protect the cabling, and finally, the new and improved star network installation would feature a cabling standard with the flexibility to enable the network to grow according to its needs and then to upgrade when the next great network technology comes along.

***Exam Tip*** - A single piece of cable that runs from a work area to a telecommunications room is called a *run*. In most networks, this cable is Cat 5e or better UTP.

###### Solid Core Versus Stranded Core
All UTP cables come in one of two types: solid core or stranded core. Each wire in solid core UTP uses a single solid wire. With *stranded core*, each wire is actually a bundle of tiny wire strands. Each of these cable types has its benefits and downsides. Solid core is a better conductor, but is pretty stiff and will break if handled too often or too roughly. Stranded core is not quite as good as a conductor, but it will stand up to substantial handling without breaking.
ANSI/TIA specifies that horizontal cabling should always be solid core.

***Exam Tip*** - The CompTIA A+ exams expect you to know that a punchdown tool is used for securing UTP connections to a punchdown block.

***Exam Tip*** - The CompTIA A+ exams expect you to know that a cable tech uses a crimper or crimping tool to attach an RJ45 to the end of a UTP cable.

#### Going Wide
A *Wide Area Network (WAN)* is a widespread group of computers connected using long-distance technologies. You connect LANs into a WAN with a magical box called a *router*. The best example of a WAN is the internet itself.
Routers destroy any incoming broadcast frames, by design. No broadcast frame can ever go through a router. To go beyond a LAN requires a network protocol - a way machines agree to communicate - that can handle routing. That protocol for the vast majority of networks, is called TCP/IP.

#### 1101
To extend the capabilities of a wireless ethernet network, you need a *wireless access point*. A WAP centrally connects wireless network devices in the same way that a hub connects wired ethernet devices. Many WAPs also act as switches and internet routers. 
 
Most WAPs draw their power from a wall outlet, but more advanced ones take advantage of a concept known as *PoE (Power over Ethernet)*. With a PoE-capable switch, both power and a data connection are provided to a compatible access point.

***Exam Tip*** - The CompTIA A+ 1101 exam objectives mention PoE standards. These include IEEE 802.3af, 802.3at, and 802.3bt (Which are marketed as PoE, PoE+, and PoE++). Make sure you recognize them!

##### Wireless Networking Software
Wireless devices use the same networking protocols and client that wired counterparts use, and they operate using what's known as *Carrier-Sense multiple access/ Collision Avoidance (CSMA/CA*). Because wireless devices have a more difficult time detecting data collisions, they offer the option of using the *Request to Send/Clear to Send (RTS/CTS)* protocol. With this protocol enabled, a transmitting device sends an RTS frame to the receiving device after it determines the wireless medium is clear to use. The receiver then responds with a CTS frame, telling the sender that its ok to transmit. Once that piece is done, then the transmitting device waits for an acknowledgement (ACK) from the receiving device before sending the next data packet.

##### Wireless Infrastructure
Wireless networks use one or more WAPs to connect the wireless network devices to a wired network segment. A single WAP servicing a given area is called a *Basic Service Set (BSS)*. This service area can be extended by adding on more access points. Office buildings and campuses may have more than one active WAP to provide good signal coverage throughout the entire area. This is called an *Extended Basic Service Set (EBSS).* They may also lean on devices known as *wireless repeaters/extenders* that rebroadcast signals from clients and WAPs to help cover dead zones. 

#### 1102

##### Wireless Networking Security
Wireless networks use three methods to secure access to the network itself and secure the data being transferred: MAC address filtering, authentication and data encryption. 

###### SSID

The *service set identifier (SSID)* parameter - also called the *network name* -- defines the wireless network. Wireless devices want to be heard, and WAPs are usually configured to announce their presence by broadcasting the SSID to their maximum range. 

Always change the default SSID to something unique and change the password right away. Configuring a unique SSID and password is the very least you should do to secure a wireless network. Keep in mind that each wireless access point in a network needs to be configured with the same unique SSID name. This SSID name is then included in the header of every data packet that is broadcast in the wireless network's coverage area. Data packets that lack the correct SSID name in the header get rejected. 

Another trick seen in wireless networks is to tell the WAP not to broadcast the SSID. In theory, people not authorized to access the network will have a harder time knowing it's there. This technique will be a question on the CompTIA A+ exam, but it is useless in real-world application.

###### Access Point Placement and Radio Power

When setting up a wireless network, keep the space in mind; you can limit risk by hiding the network from outsiders. Many wireless access points enable you to adjust the radio power levels of the antenna. Decrease the radio power until you can get reception at the furthest point inside the target network space, but not outside. This will take some trial and error.

###### Guest Networks

Some WAPs include a guest access feature that makes it easier to set up a network for untrusted users. The CompTIA A+ 1102 objectives mention *disabling guest access* as a wireless-specific security measure -- so be prepared to recognize it as a security measure on the exam. 

###### MAC Address Filtering

Most WAPs support *MAC address filtering*, a method that enables you to limit access to your wireless network based on the physical, hard-wired address of the units' wireless NIC. A table stored in the WAP lists the MAC addresses that are permitted to participate in the wireless network. Any data packets that don't contain a MAC address listed in the table are rejected.

#### 1101

##### Wireless Networking Standards and Regulations

Most wireless networks use radio frequency (RF) technologies, in particular the 802.11 (Wi-Fi) standards. These technologies use parts of the RF signal spectrum that were already in use for other purposes, so they are tightly regulated to minimize their impact on those users. 

###### IEEE 802.11-Based Wireless Networking

The 802.11-based wireless technologies broadcast and receive on one of three radio bands: 2.4 GHz, 5 GHz, and 6 GHz. A band is a contiguous range of frequencies that is usually divided up into discrete slices called *channels*. The original 802.11 standard has been extended to 802.11a, b, g, n, ac, and ax variations used in many different wireless networks.

###### Understanding Wi-Fi Channels

Each Wi-Fi channel is a little 20-MHz slice of its broader radio band. Channels operate differently between different bands, and those differences will be listed below.

In the 2.4 GHz band, most countries allow for either 11 or 13 channels, with a big catch--they overlap! Overlapping channels are not good for performance, so in the US we are limited to three non-overlapping channels: 1, 6 and 11.

Channels in the 5-GHz band thankfully are non-overlapping. The number of available channels and the exact ones that are actually available can differ from country to country. In the US, we have 25 channels to choose from. 

The 6-GHz band is already available for Wi-Fi 6E devices in some countries and is working its way through the regulatory process in others. The new band increases the space available for Wi-Fi networks, giving us many more nonoverlapping channels to spread out over. It can support up to 8 bonding channels into one super-wide 160 MHz channel!

###### 802.11a

This standard differs from the others in significant ways. This is the first Wi-Fi standard to operate in the 5GHz range. This means devices using this standard are less prone to interference from other devices that use this same frequency range. 802.11a offers throughput speeds of up to 54 Mbps, though its actual throughput is more like 25 Mbps in normal traffic conditions. Its theoretical range tops out at about 150 feet.

###### 802.11b

This standard was the first to take off and become ubiquitous in wireless  networking. This standard supports speeds of up to 11 Mbps, with actual throughput being more around 4-6 Mbps, and a maximum range of 300 feet under ideal conditions. The main downside to this standard is that it uses a very popular frequency, so you are likely to run into interference from other devices on the 2.4 GHz band.

###### 802.11g

This came out in 2003, taking the best of 802.11a and b and rolling them into a single standard. 802.11g offers transfer speeds similar to 802.11a, with the wider 300 foot range of 802.11b. This standard runs in the 2.4 GHz band, so it is backward compatible with 802.11b.


###### 802.11n

The 802.11n standard (now known as Wi-Fi 4) brought several improvements to Wi-Fi networking, including faster speeds and new antenna technology implementations. This specification requires all but hand-held devices to use multiple antennas to implement a feature called *multiple in/multiple out (MIMO)*, which enables the devices to make multiple simultaneous connections. The official standard supports throughput of up to 600 Mbps, but practical implementation drops that down to about 100 Mbps at 300+ feet.

Many 802.11n WAPs employ *transmit beamforming*, a multiple-antenna technology that helps get rid of dead spots--or at least make them not so bad. The antennas adjust the signal once the WAP discovers a client to optimize the radio signal.

###### 802.11ac

802.11ac, now known as Wi-Fi 5, is a natural expansion of the 802.11n standard, which incorporates even more streams, wider bandwidth and higher speeds. 802.11ac only uses the 5GHz band to avoid device density issues. This standard includes a new version of MIMO known as *Multi-user MIMO (MU-MIMO)*. This feature gives a WAP the ability to broadcast to multiple users simultaneously.

###### 802.11ax

This standard, known as *high efficiency wireless (HEW)*, brings a number of improvements that can help congested networks. This standard is marketed as *Wi-Fi 6 and Wi-Fi 6E*. Devices with 802.11ax can use both the 2.4 and the 5GHz bands, but newer Wi-Fi 6E devices can also use the new 6 GHz band.

***Exam Tip*** - Be prepared to answer questions about Wi-Fi 6 or Wi-Fi 6E on the exam!

#### Optimizing Wi-Fi Coverage

Wireless networking data throughput speeds and coverage depend on many factors, but the most important are the wireless standards in use, the distances involved, the amount of interference present, and the kind of antennas in use. One factor affecting speed is the distance between wireless clients and their access points. Wireless devices dynamically negotiate the top speed at which they can communicate without dropping too many data packets. Speed decreases as distance increases.

Interference caused by solid objects and other wireless devices operating in the same frequency range can reduce both speed and range for wireless clients.

***Exam Tip*** - Look for basic troubleshooting questions on the CompTIA A+ exams dealing with factors that affect wireless connectivity, range and speed.

##### Antennas and Transmission Power

Most wireless networks use standard straight-wire *dipole antennas* to provide omni-directional coverage. They look like a stick, but they have two antenna arms or poles aligned on their axes. Increasing the size of a dipole will increase its *gain* evenly in all directions. Directional antennas--such as parabolic dish-type antennas--increase gain in a specific direction and reduce gain in all other directions.

***Exam Tip*** - If you want to know if an access point is nearby, you can use a *wireless locator*

###### Long-Range Fixed Wireless

This type of wireless uses directional antennas and is a great way to interconnect remote buildings when it's hard to physically run cable to them. Powerful directional antennas enable organizations to provide a remote building or structure with network access (up to several miles away) without having to run cable to it. There isn't really a specific set of standards for these *point-to-point* connections, but there are some regulatory requirements.

Just like with regular Wi-Fi networks, the level of transmission power plays a big role in the distance you can communicate over. Signals with higher transmit power can travel farther and penetrate more obstacles.

#### Bluetooth
Bluetooth wireless technology is designed to create small wireless networks, usually known as *Personal Area Networks (PANs)*. These networks are preconfigured usually to do very specific jobs.

***Exam Tip*** - PANs are the smallest area network type included in the CompTIA A+ 1101 objectives. Their scope is exactly what it says on the tin -- devices that belong to and are near or on a single person.

The IEEE organization has made first-generation bluetooth the basis for its 802.15 standard for wireless PANs. Bluetooth uses a broadcasting method that switches between any of the 79 frequencies available in the 2.45 GHz range. Bluetooth hops frequencies some 1600 times per second, making it highly resistant to interference.

### 1101

#### Connecting to the Internet
Computers commonly connect to an ISP through their wired or wireless router. If the customer purchased the router, it will have an ethernet connection to a box (often called a modem) that interconnects it with the ISP's network. If the customer leased a router from their ISP, it will often have a built-in modem.

#### DSL
*Digital Subscriber Line (DSL)* connections to ISPs use a standard telephone line with special equipment on each end to create always-on internet connections.

#### Cable

Cable offers a different approach to high-speed internet access, using regular cable TV cables to serve up lightning-fast speeds. Cable internet connections are theoretically available anywhere you can get cable TV. These connections start with an RG-6 or RG-59 (Coax) cable coming into your house. The cable connects to a *cable modem* that then connects to a small home router, or your NIC via Ethernet.

#### Fiber

DSL providers have developed very popular fiber deployments for internet connections, such as FTTN (fiber-to-the-node), and FTTP (fiber-to-the-premises). Entrants like Google Fiber and local municipalities have added momentum to the fiber rollout. 

With FTTN, the fiber connection runs from the provider to a box somewhere in your neighborhood. This box connects to your home or office using normal coaxial or Ethernet cabling. FTTP runs from the provider straight to a box in your home or office, using fiber the whole way. This box is known as an *optical network terminal*. The ONT has an input for the fiber connection, and an Ethernet or coax connection for a router which then provides wireless to connect your computers to the internet.

#### Wi-Fi

Wi-Fi, or 802.11 wireless, serves as another method of connecting to the internet. One popular form of wireless internet service, known as a *wireless Internet Service Provider (WISP)*, works similarly to a traditional wired internet service, but with a catch. The last segment of the connection uses a point-to-point long range fixed wireless connection.

#### Cellular

The most common way to access the internet through a cellular connection is with a mobile device. This is known as a *wireless WAN* according to the CompTIA A+ 1101 exam objectives.

#### Satellite

Satellite connections to the Internet get the data beamed to a satellite dish on your house or office.

All SOHO routers use a technology called Network Address Translation, which presents an entire LAN of computers to the internet as a single machine. In essence, it effectively hides all of your computers and makes them appear invisible to other machines on the internet. All the internet sees is your public IP address.

***Exam Tip*** - Many computers can share a smaller pool of routable IP address with dynamic NAT (DNAT). A NAT might have 10 routable IP addresses, to serve 40 computers on the LAN. LAN traffic uses the internal private IP addresses. When a computer requests information beyond the network, the NAT doles out a routable IP address from its pool for that communication.

#### Internet Application Protocols
Application developers turn to well-known application protocols that anyone can use. Web browsers use HTTP (Hypertext Transfer Protocol) to send web pages and related resources. E-mail clients use Post Office Protocol 3 (POP3) or Internet Message Access Protocol (IMAP) to receive email and Simple Mail Transfer Protocol to send e-mail.

Each protocol has its own rules and port numbers. Most sensitive information sent over the web for example, uses HTTPS, with port 443 for encryption. CompTIA wants you to understand the following applications listed below:

1. World Wide Web (HTTP and HTTPS)
1. E-mail (POP3, IMAP and SMTP)
1. Telnet
1. SSH
1. FTP/SFTP
1. Remote Desktop Protocol (RDP)
1. VoIP (SIP)

- **MIMO**: Multiple Input Multiple Output increases data rates by allowing multiple devices to connect simultaneously.

#### Hardware Virtualization

One of the most important kinds of virtualization, *hardware virtualization*, takes the entire computer that an OS expects to interact with and virtualizes it. The physical *host* computer uses software known as a *hypervisor* to create environments that have virtual versions of all the "hardware" devices you need to install and run an OS. 

***Exam Tip*** - If you see virtualization on the exam, it will almost certainly mean hardware virtualization.

The CompTIA A+ 1101 objectives expect you to be able to *summarize the purpose of virtual machines*.

##### Client-Side Virtualization

A normal operating system installed directly on the hardware uses programming called a *supervisor* (better known as the *kernel*) to handle very low-level interaction among hardware and software, like task scheduling, allotment of time and resources and so on. Hardware virtualization enables one machine - the host - to run multiple guest operating systems simultaneously. The CompTIA A+ 1101 objectives focus mostly on what CompTIA calls *client-side virtualization* - when the VM host also serves as someone's day-to-day workstation.

***Exam Tip*** -  If you see terms like "client-side" and "virtualization" in the same question on the exam, keep an open mind! This usually refers to where computing work is done. 

In hardware virtualization, the hypervisor takes on the role of the supervisor - plus the added chore of dividing up the hardware resources among active virtual machines.

##### Benefits of Virtualization

Hardware virtualization unlocks a lot of little benefits, so we will focus on two big categories: saving resources and making systems easier to manage.

###### Saving Resources

The flexibility of virtual machines makes it possible to consolidate multiple systems down into a single box. Hardware consolidation also reduces the time and money and organization spends maintaining hardware and enables it to entirely avoid purchasing expensive hardware that rarely ever runs at full capacity during its useful lifetime.

###### Simplifying System Management and Security

The most popular reason for virtualizing is probably the benefits that we reap from easy-to-manage systems. VMs are simply files: like any other files, they are easy to copy around. Most virtual machines also let us make a *snapshot or checkpoint*, which saves the virtual machine's state at that moment, allowing us to quickly return to this same state later.

##### Server-Side Virtualization

When it comes to servers, hardware virtualization has taken over pretty much everywhere. Many of the servers we access every day are actually virtualized. Most server VMs run on a powerful hypervisor/OS combination called a *bare-metal hypervisor*. There is no other software between it and the hardware - just bare metal. These are also known as *Type-1 hypervisors*, while application hypervisors are regarded as *Type-2*.

#### To the Cloud

When we talk about *the cloud*, we are talking about all of the services that enable us to dip into the vast pools of computing resources sold by Amazon, Microsoft, and many other companies over the open Internet.

##### The Service-Layer Cake

Service is the key to understanding the cloud. We use the servers and networks of the cloud through layers of software that add great value to the underlying hardware by making it simple to perform complex tasks or manage powerful hardware.

###### Infrastructure as a Service (IaaS)

Large-scale global *Infrastructure as a Service* providers use hardware virtualization to minimize idle hardware, protect against data loss and downtime, and respond to spikes in demand. We can use big IaaS providers like Amazon Web Services to launch new virtual servers using an operating system of choice on demand for pennies an hour. The benefit to IaaS is that you do not need to purchase expensive, heavy hardware. If you want someone to handle the infrastructure, the operating system, and everything else besides your application, we need to move up to Platform as a Service (PaaS).

###### Platform as a Service

A *Platform as a Service (PaaS)* provider gives programmers all the tools they need to deploy, administer, and maintain a web application. The PaaS provider is aware of their infrastructure, but the developer cannot control it directly, and does not need to think about its complexity.

###### Software as a Service

*Software as a Service (SaaS)* shows up in a number of ways, with some of the best examples being web-based applications. The SaaS model provides access to necessary applications wherever you have an Internet connection, often without having to carry data with you or regularly update software.

***Exam Tip*** -  Know the differences between basic cloud concepts such as SaaS, IaaS, and PaaS.

#### Ownership and Access

###### Public Cloud
Most people interact with what is known as a *public cloud*, a term used to describe software, platforms and infrastructure delivered through networks that the general public can use. 

###### Private Cloud
If a business wants some of the flexibility of the cloud, but needs complete ownership of the data, and can afford both, then it can build an internal cloud the company actually owns. This is a *private cloud*.

###### Community Cloud
A *community cloud* is like a private cloud paid for and used by more than one organization. The community in this case is a group of organizations with similar goals or needs.

###### Hybrid Cloud
We can build a *hybrid cloud* by connecting some combination of public, private, and community clouds, allowing communication between them. One example where a hybrid cloud can be useful is from a technique called *cloud bursting*, which is where an application can grow into a public cloud instead of grinding to a halt.

***Exam Tip*** - Know the differences between public, private, community and the hybrid cloud models

##### Cloud Characteristics
Here are five key cloud characteristics that CompTIA wants you to know for the exam:

###### Shared Resources
Cloud computing focuses less on individual systems and more on the underlying resources. Instead of renting out physical units, cloud providers aggregate them into a pool of *shared resources* that they can then make available on-demand. The provider's customers draw from this pool as they need additional resources and then release them back into the pool when they are done.

###### Rapid Elasticity
Using the features of the cloud, you can easily expand the number of servers an application uses and also spread them out geographically with just the click of a button. This is known as *rapid elasticity*.

###### Metered Utilization
Most cloud providers charge a precise *metered utilization* rate based on factors such as the traffic that goes in and out of your web application and how much data you store. With metered utilization, you pay for what resources you use, rather than a more general fee for all of the hardware of a system.

###### High Availability
Cloud computing enables organizations to get as close to 100 percent uptime as they can afford. Organizations can also design their cloud deployments for *high availability* - for example, they can set up redundant servers around the world and automatically reroute traffic when a server goes down.

###### File Synchronization
Cloud file storage services like Dropbox for example provide *file synchronization* apps that propagate file changes to the storage provider on to any other connected devices.

##### Desktop Virtualization
Desktop virtualization tries to apply the flexibility associated with both hardware virtualization and cloud computing to user workstations. The most common form of *desktop virtualization* entails using a client program on one device to connect to a *virtual desktop*, providing access to a user's files and applications. The CompTIA A+ 1101 objectives focus on something called *virtual desktop infrastructure (VDI)*, where each user's client program connects to an automatically managed virtual machine running on a central server.

### 1101

#### Printer and Multifunction Device Consumables

##### Printers
Modern printers can be categorized into several types: impact, inkjet, thermal, laser, 3-D and virtual.

###### Impact Printers
Printers that create an image on paper by physically striking an ink ribbon against the paper's surface are known as *impact printers*. Although *daisy-wheel* printers (essentially an electric typewriter) have largely disappeared, their cousins, known as *dot-matrix printers*, still soldier on in many offices

dot-matrix printers can be used for multipart forms because they actually strike the paper. Computers that print multipart forms, such as *point of sale* machines, use special *impact paper* that can print receipts in duplicate, triplicate, or more. Dot-matrix printers use a grid of tiny pins, known as printwires, to strike an inked printer ribbon and produce images on paper. The case that holds the printwires is known as a *printhead*. 

Using either 9 or 24 pins, dot-matrix printers treat each page as a picture broken up into a dot-based raster image. The BIOS for the printer interprets the raster image in the same way a monitor does, by "painting" the image as individual dots. Some dot-matrix printers use continuous-feed paper with holes on its sides that are engaged by metal sprockets to pull the paper through -- this is known as *tractor-feed paper*.

###### Inkjet Printers

*Inkjet printers* use a printhead connected to a *carriage* that contains the ink. A *carriage belt* and motor move the carriage back and forth so the ink can cover the whole page. A *roller* grabs paper from a paper tray (usually under or inside the printer) or *feeder* (usually on the back of the printer) and advances it through the printer.

The ink is ejected through tiny tubes. Most inkjet printers use heat to move the ink, while a few use a mechanical method. The heat-method printers use tiny resistors at the end of each tube that literally boil the ink; this creates a tiny air bubble that ejects a droplet of ink onto the paper, which creates a portion of the image.

The ink is stored in special *ink cartridges*. Printer manufacturers began to separate the ink colors into three separate cartridges so that printers came with four, with the fourth color being black (CMYK). 

The two key features of an inkjet printer are the print resolution -- how densely the printer lays down ink on the page -- and the print speed. Resolution is measured in *dots per inch (DPI)*. Higher numbers mean that the printouts will look better. Print speed is measured in *pages per minute (PPM)* and this is normally specified on the printer's box.

###### Thermal Printers
Thermal printers use a heated printhead to create a high-quality image on special or plain paper. You will see two kinds of thermal printers in use today. The first is the *direct thermal*, and the other is the *thermal wax transfer* printer. Direct thermal printers use a *heating element* to burn dots into the surface of special *heat-sensitive thermal paper*. Many retail businesses still use it as a receipt printer, using large rolls of thermal paper housed in a *feeding assembly* that automatically draws the paper past the heating element.

###### Laser Printers
Using a process known as *electro-photographic imaging, laser printers* produce high-quality and high-speed output of both text and graphics. Laser printers rely on the photoconductive properties of certain organic compounds. The CompTIA A+ exams take a keen interest in the particulars of the laser printing process, also known as the *imaging process*. Here we will look at the different components of a laser printer:

###### Toner Cartridge
The *toner cartridge* in a laser printer is named because its purpose is supplying the toner that creates the image on the page. 

###### Imaging Drum
The *imaging drum* (also called the photosensitive drum) is an aluminum cylinder coated with particles of photosensitive compounds. The drum itself is grounded to the power supply, but the coating is not. When light hits these particles, whatever electrical charge they may have "drains" out through the grounded cylinder.

###### Erase Lamp
The *erase lamp* exposes the entire surface of the imaging drum to light, making the photosensitive coating conductive. Any electrical charge present in the particles bleeds away into the grounded drum, leaving the surface particles electrically neutral.

###### Primary Corona/Charge Roller
The *primary corona* wire (or *primary charge roller*), is located close to the imaging drum, but never touches the drum. When the primary corona or charge roller is charged with an extremely high voltage, an electric field forms, enabling voltage to pass to the drum and charge the particles on its surface. The primary grid regulates the transfer of voltage, ensuring that the surface of the drum receives a uniform negative voltage of between ~600 and ~1000 volts.

###### Laser
The *laser* acts as the writing mechanism of the printer. Any particle on the drum struck by the laser becomes conductive and its charge is drained away into the grounded core of the drum. The entire surface of the drum has a uniform negative charge of around ~750 volts following its charge by the corona wire. When particles are struck by the laser, they are discharged and left with a ~100-volt negative charge. Using the laser, we can "write" an image onto the drum. Note that the laser writes a positive image to the drum.

###### Toner
The *toner* in a laser printer is a fine powder made up of plastic particles bonded to pigment particles. The toner cylinder charges the toner with a negative charge of between ~200 and ~500 volts. Because that charge falls between the original uniform negative charge of the imaging drum and the charge of the particles on the drum's surface hit by the laser, particles of toner are attracted to the areas of the imaging drum that have been hit by the laser.

**Exam Tip*** - The black toner used in laser printers is typically carbon mixed into polyester resin, while color toner trades carbon for other pigments.

###### Transfer Corona/Transfer Roller
To transfer the image from the imaging drum to the paper, the paper must be given a charge that will attract the toner particles off of the drum and onto the paper. A *transfer roller* will accomplish this by drawing the toner onto the paper. The paper, with its positive charge, is also attracted to the negatively charged drum. To prevent the paper from wrapping around the drum, a *static charge eliminator* removes the charge from the paper.

Most printers with an exposed transfer roller provide a special tool to clean it, but you can also use a cotton swab soaked in denatured alcohol (don't use rubbing alcohol because it contains emollients). 

###### Fuser Assembly
The *fuser assembly* is almost always separate from the toner cartridge. It is usually quite easy to locate, as it is close to the bottom of the toner cartridge and usually has two rollers to fuse the toner. Sometimes the fuser is somewhat enclosed and difficult to recognize because the rollers are hidden from view. 

The toner is merely resting on top of the paper after the static charge eliminator has removed the paper's static charge. The toner must be melted to the paper to make the image permanent. Two rollers, a pressure roller and a heated roller, are used to the fuse the toner to the paper. The pressure roller presses against the bottom of the page, and the heated roller presses down on the top of the page, melting the toner into the paper. The heated roller has a nonstick coating such as Teflon to prevent the toner from sticking to it.

###### Power Supplies
All of the devices described above have power supplies. Before performing any maintenance of any kind, turn off and unplug the printer as a safety precaution.

###### Turning Gears
A laser printer has many mechanical functions. First, the paper must be grabbed by the *pickup roller* and passed over the *separation pad*, which is a small piece of cork or rubber that separates the sheets as they are pulled from the paper feed tray. A separation pad uses friction to separate a single sheet from any others that were picked up. Next, the photosensitive roller must be turned and the laser, or a mirror, must be moved back and forth. The toner must be evenly distributed, and the fuser assembly must squish the toner into the paper. Finally, the paper must by kicked out of the printer and the assembly must be cleaned to prepare for the next page.

**Exam Tip*** - Be sure you are familiar with laser printer components, in particular the imaging drum, fuser assembly, transfer belt, transfer roller, pickup rollers, separation pads, and duplexing assembly.

###### 3-D Printers
*3-D printers* use melted material to create prints of three-dimensional objects.  The flat surface from which the printer deposits this melted material to build an object is called the *print bed*. The most common 3-D printers use *plastic filament* or *resin* on spools.

3-D printers take a 3-D illustration and build it in tiny layers or slices, one by one. The filament printers work by melting the plastic and allowing it to cool as the 3-D image builds. Resin printers work by placing liquid resin down and curing it with UV light.

###### Printer Languages
How do we actually get a printer to make a letter A for example? The software must use the proper language when communicating with a printer in order to make this happen. 

**Exam Tip*** - One thing to remember for the exam is the importance of choosing the appropriate driver for the OS. A common printing mistake, for example, is that you may be printing to a PostScript printer with a PCL driver.

###### PostScript
Adobe Systems developed the PostScript page description language back in the 1980s. PostScript defines the page as a single raster image. 

###### HP Printer Command Language
HP developed its *Printer Command Language* as a more advanced printer language to supersede simple ASCII codes. PCL uses a series of commands to define the characters on the page.

**Exam Tip*** - The CompTIA A+ Acronym list defines PCL as *Printer Control Language*. 

**Exam Tip*** - Laser and inkjet printers can also use *duplexing assemblies*, which enable the printer to automatically print on both sides of the paper.

#### The Laser Printing Process
The *imaging process* with a laser printer breaks down into seven steps, and the CompTIA A+ 1101 exam expects you to know them all. The seven steps to the laser printing process may be performed in a different order, but it usually goes like this:

1. Processing
2. Charging
3. Exposing
4. Developing
5. Transferring
6. Fusing
7. Cleaning

##### Processing
When you click the Print button in an application, several things happen. First, the CPU processes your request and sends the print job to an area of memory called the print spooler. The *print spooler*
 enables you to queue up multiple print jobs that the printer handles sequentially. Next, Windows sends the first print job to the printer. Once the printer receives some or all of a print job, the hardware of the printer takes over and processes the image. 

###### Raster Images
A laser printer uses a chip called the *raster image processor (RIP)* to translate a raster image into commands to the laser. The RIP takes the digital information about fonts and graphics and converts it to a rasterized image made up if dots that can then be printed. The RIP needs memory (RAM) to store the data that it must process.

##### Charging
To make the drum receptive to new images, it has to be charged.  Using the primary corona wire or primary charge roller, a uniform negative charge is applied to the entire surface of the drum, usually between ~600 and ~1000 volts.

##### Exposing
A laser is used to create a positive image on the surface of the drum. Every particle on the drum hit by the laser releases most of its negative charge into the drum.

##### Developing
Those particles with a lesser negative charge are positively charged relative to the toner particles and attract them, creating a developed image.

##### Transferring
The printer must transfer the image from the drum onto the paper. The transfer corona or transfer roller gives the paper a positive charge; then the negatively charged toner particles leap from the drum to the paper. At this point, the particles are resting on the paper and must still be permanently fused onto it.

##### Fusing
The particles have been attracted to the paper because of the paper's positive charge, but if the process stopped here, the toner particles would fall off the page as soon as you lift it. Because the toner particles are mostly composed of plastic, they can be melted to the page. Two rollers -- a heated roller and a pressure roller -- melt the toner to the paper, permanently affixing it. Finally, a static charge eliminator removes the paper's positive charge. Once the page is complete, the printer ejects the printed copy and the process begins again with the physical and electrical cleaning of the printer.

##### Cleaning
The printing process ends with the physical and electrical cleaning of the imaging drum. Before printing another new page, the drum must by returned to a clean, fresh condition. All residual toner left over from the previous print job must be removed, usually by scraping the surface of the drum with a rubber cleaning blade. The physical cleaning mechanism either deposits the residual toner in a debris cavity or recycles it by returning it to the toner supply in the toner cartridge. 

The printer must also be electrically cleaned. One or more erase lamps bombard the surface of the drum with the appropriate wavelengths of light, causing the surface particles to discharge into the grounded drum. After the cleaning process, the drum should be completely free of toner and have a neutral charge.

### The Laser Printing Process: A Step-by-Step Explanation

Laser printers operate through a series of steps that convert digital data into a printed image on paper. Here's a detailed breakdown of each step involved in the laser printing process:

1. **Processing (Data Preparation):**
   - When you click "Print" in an application, your CPU sends the print job to the print spooler.
   - The print spooler queues up multiple jobs and processes them sequentially.
   - A *RIP* (Raster Image Processor) converts digital data into a rasterized image composed of dots that can be printed. This step requires sufficient RAM for efficient processing.

2. **Charging:**
   - The imaging drum is charged using the primary corona wire or charge roller, applying a uniform negative charge (typically between 600-1000 volts).
   - This charging process makes the drum receptive to new images.

3. **Exposing:**
   - A laser is used to create a positive image on the drum's surface by hitting specific areas with light.
   - Particles hit by the laser release most of their negative charge into the drum.

4. **Developing:**
   - Toner particles that have a lesser negative charge attract and stick to these positively charged areas, creating a developed image.

5. **Transferring:**

   - Negatively charged toner particles are attracted to the paper, landing on its surface.

6. **Fusing:**
   - A heated roller melts the plastic in the toner particles, fusing them permanently onto the paper.
   - A pressure roller ensures even contact and fusion of toner onto the paper.

7. **Cleaning:**
   - After printing, residual toner is physically scraped off using a rubber blade or similar tool.
   - The imaging drum is electrically cleaned using lamps that discharge toner particles into the grounded drum.
   - This ensures the drum is clean and ready for the next print job.

#### Analyzing Threats and Vulnerabilities

A *vulnerability* is a weak spot in your defenses that enables a threat to cause harm. Vulnerabilities can exist either in physical security or in an organization's networks. 

#### Threats
We are going to look at the following issues related to threats:
1. Malicious Actors
2. Unauthorized Access
3. Social engineering
4. Insider threats
5. Data destruction, whether accidental or deliberate
6. Administrative access
7. System crash/hardware failure
8. Physical theft
9. Malware
10. Spam

##### Malicious Actors
In some cases, the threat in question is an individual, also known as a *threat actor*. Threat actors need some way to use vulnerabilities to their advantage. This is known as an *attack*, or an *exploit*. Very rarely will a malicious actor make use of only one attack vector or method of entry. For example, a malicious actor attacking from outside may employ a phishing scam to gain user login credentials, use those credentials to then gain initial access to a network, and then deploy a zero-day attack to take over the network admin's account.

**Exam Tip*** - Be aware that while many of these terms are considered types of attacks, CompTIA's A+ 1102 exam objectives classify them all as *social engineering* or *threats*.

##### Zero-Day Attack
A *zero-day attack* is an attack on a vulnerability that wasn't already known to the software developers. 

##### Spoofing
*Spoofing* is the process of pretending to be someone or something you are not by placing false information into your packets. Any data sent on a network can be spoofed.

##### On-Path Attack
In an *on-path attack*, an attacker taps into communications between two systems, covertly intercepting traffic thought to be only between those systems, reading or in some cases even changing the data and then sending the data on. 

**Exam Tip*** - While CompTIA prefers to use the term on-path attack, you will more commonly hear it referred to by its original name, man-in-the-middle out in the world.

##### Session Hijacking
Similar to on-path attacks, *session hijacking* tries to intercept a valid computer session to get authentication information. Session hijacking only tries to grab authentication information though, not listening in like an on-path attack.

##### Brute-Force Attack
Any attempt to guess the contents of some kind of data field that isn't obvious is considered a *brute-force attack*. There are two other tools that attackers use to brute force passwords though: dictionaries and rainbow tables. A *dictionary attack* is a form of a brute force attack that guesses every word in a dictionary. A *dictionary* used to attack passwords might contain every password ever leaked online. Another common attack used is with *rainbow tables*, which are binary files that use complicated math to condense dictionary tables with hashed entries dramatically.

##### Cross-Site Scripting
An attack that can pose a serious threat to web applications is *cross-site scripting*. This is an attack in which the attacker injects malicious code into the web app in order to trick it into sending things it should not to other users of the web site.
